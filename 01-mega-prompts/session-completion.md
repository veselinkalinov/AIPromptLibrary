# SESSION COMPLETION MEGA PROMPT

**Use before ending every work session.**

> Captures session output, surfaces unresolved items, and prepares context for next session initialization.

---

Before we close this session, run through the following:

**1. Session Output Summary**

List everything we produced or decided in this session:
- Files created or modified
- Decisions made
- Code written
- Problems solved

**2. Open Threads**

What is unresolved, deferred, or incomplete? List each item with enough context to pick it up cold next session.

**3. Blockers**

Are there any blockers I need to resolve before the next session? (External dependencies, missing information, decisions I need to make.)

**4. Next Session Primer**

Write a 3–5 sentence briefing I can paste at the start of our next session to restore context immediately — without re-reading this conversation.

**5. Critical Risks or Warnings**

Flag anything that could break, regress, or cause problems if left unaddressed before next session.

---

Format each section clearly. Be specific — vague summaries are useless when context resets.
