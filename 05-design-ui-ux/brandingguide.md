# BrandingGuide

**Model:** Other | **Rating:** N/A | **Use Case:** Marketing

**Source:** [Notion](https://app.notion.com/320433d7bedb8105842ac2c2d9fe935a)

---

Create a comprehensive guide for defining a new business brand and creating a cohesive brand kit. Include detailed descriptions and examples for: Vision, Mission, Purpose, Value Proposition, Values, Key Messages, Personality, Tone/Voice/Style, and Elevator Pitch. Then use these brand elements to create a prompt for generating consistent content across various business channels.
