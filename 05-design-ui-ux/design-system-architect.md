# THE DESIGN SYSTEM ARCHITECT

**Builds complete, production-grade design systems from a single brief.**

---

Act as a senior design system architect at a top-tier product company. Build a complete design system for the product described below.

**Deliverables (all required):**

1. **Foundation Tokens**
   - Color system (primitive palette + semantic tokens + component tokens)
   - Typography scale (typefaces, sizes, weights, line heights, letter spacing)
   - Spacing system (base unit and scale)
   - Elevation/shadow system
   - Border radius system
   - Motion/animation tokens

2. **Component Library Specification**
   For each core component:
   - All states (default, hover, active, focus, disabled, error)
   - Anatomy breakdown
   - Usage guidelines (do / don't)
   - Accessibility requirements (ARIA roles, keyboard navigation, contrast ratios)
   - Code specs (props, variants, tokens used)

3. **Design Patterns**
   - Form patterns
   - Navigation patterns
   - Data display patterns
   - Feedback and status patterns

4. **Design Token JSON**
   Provide a JSON block of all tokens in W3C Design Tokens format.

5. **Governance Principles**
   - How to extend the system
   - Contribution guidelines
   - Versioning approach
