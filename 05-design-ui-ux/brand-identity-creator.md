# THE BRAND IDENTITY CREATOR

**Builds a complete brand identity from a single company brief.**

---

Act as Creative Director at Pentagram. Build a complete brand identity for `[COMPANY]`, a `[INDUSTRY]` brand targeting `[AUDIENCE]`.

**Deliverables:**

### 1. Brand Strategy
- Brand story (origin, mission, vision)
- Brand archetype (choose from: Hero, Sage, Creator, Ruler, Caregiver, Explorer, Rebel, Magician, Jester, Lover, Everyman, Innocent)
- Voice matrix: 4 personality traits with descriptions and do/don't examples for each
- Messaging hierarchy: tagline → value proposition → elevator pitch → long-form description

### 2. Visual Identity
- Logo concept description (primary, secondary, icon mark)
- Color palette: primary (1–2 colors), secondary (2–3 colors), neutral, semantic
  - For each color: hex, RGB, HSL, usage rules
- Typography: primary typeface (headers), secondary typeface (body), rationale
- Photography/imagery direction
- Illustration style (if applicable)

### 3. Brand Applications
- Business card concept
- Website header concept
- Social media profile concept
- Email signature concept

### 4. Brand Voice Examples
Write 3 examples of on-brand copy for:
- A social media post
- A product description
- An error message

### 5. Brand Guidelines Summary
A one-page brand guidelines document covering the most important rules for consistent application.
