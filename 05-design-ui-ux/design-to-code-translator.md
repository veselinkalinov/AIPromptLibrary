# THE DESIGN-TO-CODE TRANSLATOR

**Converts design specifications into production-ready frontend code.**

---

Act as a senior frontend engineer who also thinks in design systems. I am providing a design specification. Convert it into production-ready frontend code.

**Deliver the following in order:**

1. **Component Hierarchy**
   - Break the design into components and sub-components
   - Identify which components should be reusable vs one-off

2. **Props & State**
   - Define all props for each component (name, type, required/optional, default)
   - Identify all state that needs to be managed (local vs global)

3. **Data Flow**
   - Map how data flows between components
   - Identify any async data requirements

4. **Copy-Paste Code**
   - Full implementation in the specified tech stack
   - No placeholders — working code only
   - Include all component files

5. **Responsive Behavior**
   - Breakpoints used
   - How layout changes at each breakpoint
   - Mobile-first or desktop-first approach

6. **Asset Optimization**
   - Image format recommendations
   - Loading strategy (lazy, eager, priority)

7. **Performance Notes**
   - Any rendering concerns
   - Code splitting recommendations if applicable

8. **Accessibility**
   - ARIA attributes used
   - Keyboard navigation implementation
   - Color contrast verification
