# GRANT PROPOSAL TEMPLATE

**Generates a comprehensive grant proposal for any project or organization.**

---

Create a comprehensive grant proposal for the project described below.

**Project context:**

```
Organization name: []
Project title: []
Grant amount requested: []
Funding body / grantor: []
Deadline: []
Project duration: []
```

**The proposal must include:**

### 1. Executive Summary
- One-page overview of the project, need, approach, and expected outcomes
- Why this organization is uniquely positioned to deliver

### 2. Needs Assessment
- Evidence base for the problem being addressed (statistics, research, local data)
- Who is affected and how
- Why existing solutions are insufficient

### 3. Project Description
- Goals and objectives (SMART)
- Activities and timeline (Gantt chart or milestone table)
- Methodology and approach
- Staffing and organizational capacity

### 4. Evaluation Plan
- How success will be measured
- Data collection methods
- Reporting schedule

### 5. Budget Narrative
- Itemized budget with justification for each line
- Cost-effectiveness argument
- Other funding sources (if applicable)

### 6. Sustainability
- How the project continues after grant funding ends
- Long-term funding strategy

### 7. Organizational Background
- Mission and history
- Relevant past projects and outcomes
- Key personnel and qualifications
