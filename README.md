## How to Use

Each prompt lives in its own `.md` file. Every file follows this structure:

```
# Prompt Title
## EN / BG Header (for bilingual prompts)
---
[prompt body — copy everything below the divider]
```

**Bilingual prompts** have both the English and Bulgarian versions in the same file — the header identifies which is which.
