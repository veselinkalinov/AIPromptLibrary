# Create Cognitive Function Test Email

**Model:** Other | **Rating:** N/A | **Use Case:** General

**Source:** [Notion](https://app.notion.com/320433d7bedb816e89faf93564898cd3)

---

Create a professional and persuasive outreach email targeted at academic or clinical researchers, aimed at promoting a validated cognitive function test for research use. Include: compelling subject line, strong opening paragraph establishing credibility, description of the test with scientific validation, key strengths (reliability, validity, user-friendliness, research domains), benefits for researchers, and a clear call-to-action.
