# Simple Explanation of a Topic

**Model:** ChatGPT | **Rating:** ⭐⭐⭐ | **Use Case:** General, Studying

**Source:** [Notion](https://app.notion.com/3a9433d7bedb8026adb4d517c4cc5e02)

---

Explain [TOPIC] in simple, plain English for a beginner.
Requirements:
• Start with a one-sentence definition.
• Explain the main idea step by step.
• Define every important term in easy words.
• Use one clear, practical example.
• Compare it with similar concepts when useful.
• Point out common misunderstandings.
• End with a short summary of the easiest way to remember it.
• Avoid unnecessary jargon, advanced details, and overly long explanations.
• Use short sections and simple code examples if the topic involves programming.
