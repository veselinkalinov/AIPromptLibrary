# Create M&A Analysis

**Model:** Other | **Rating:** N/A | **Use Case:** Analysis

**Source:** [Notion](https://app.notion.com/320433d7bedb813bb54ed6592453f2e7)

---

Create a detailed analysis focusing on the mergers and acquisitions (M&A) landscape for a business, incorporating data from multiple Excel files. Include: M&A Report with key trends, Financial Overview and Trends with insights into financial health, SWOT Analysis, Owner Questions for investment decisions, Investment Analysis with industry-specific research, and Industry Context with benchmarks. Format professionally for an M&A expert presentation.
